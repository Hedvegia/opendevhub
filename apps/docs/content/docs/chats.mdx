---
title: Chats
description: Talk to an agent in an existing checkout, then turn the conversation into a task.
icon: MessagesSquare
---

Choose a project at the top of the sidebar and open **New chat**. Pick its main checkout or a worktree beneath the composer, then send a message to start a conversation there. The sidebar shows recent chats for the selected project; **Chats** lists them across projects.

The composer lets you choose an agent and model, attach files, use `/` commands, and mention files or agents with `@`. You can change the agent or model in later messages. If an agent is working, a new message queues behind its current turn. The conversation shows its messages and tool activity; its checkout's changes and terminal are available in the side panel.

Use **Start as task** from the new chat composer when the prompt should create a new worktree. From a chat already in a worktree, **Make task** adopts its conversation as the first variant. You can edit the suggested brief, attach a Jira ticket or pull request, choose a spec-first task, and add model variants in separate worktrees. **Archive** hides a chat from the lists while its conversation keeps running.

See [Tasks](/docs/tasks) for task variants, review and publishing.
