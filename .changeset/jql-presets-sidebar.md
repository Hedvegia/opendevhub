The sidebar's header holds the project's Overview, Pull requests and Tickets (filtered to what the project is linked to) in place of Jump to and the footer buttons. The Tickets page takes raw JQL as a filter and saves views as presets, and a project can be linked to tickets by JQL as well as by board. The composer offers Start when its container is stopped, and Chat's start page can hand its message to New task.
