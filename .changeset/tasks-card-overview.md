A project's tasks live in one Tasks card on its overview, filtered by state (Open, Needs you, Working, Idle, Drafts, Ended) and by title, in place of the sidebar's Tasks button and the overview's separate Drafts, Tasks and Ended tasks sections. Tasks waiting on you answer in place inside the card, and ended ones archive from it. The sidebar no longer lists the linked repository's open pull requests; its Pull requests button opens them. The composer's agent picker starts at the first agent opencode lists instead of showing no agent.
